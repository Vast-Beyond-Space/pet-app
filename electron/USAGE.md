# 桌宠小屋 · 使用说明

> 基于 Electron 的桌面宠物应用：AI 聊天、语音交互（TTS/STT）、屏幕感知、桌面游荡、记忆系统，并可与 **DeepSeek Harness（DSH）** 联动感知 Agent 任务状态。

本文覆盖三部分：**① 安装**、**② 打包**、**③ 设置面板每一项的完整说明**（含 DSH 联动专题）。

## 一、安装

### 1. 环境要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10/11 x64（主要目标平台） |
| Node.js | 14+（建议 18+） |
| 网络 | 联网（首次安装需下载嵌入式 Python / STT 模型；运行时 Edge TTS、DeepSeek、智谱 API 需联网） |
| 麦克风 | 陪伴模式语音输入需要 |

> 体积较大的二进制（嵌入式 Python 运行时 zip、STT 模型 zip）**不随源码分发**，`npm install` 会在联网状态下自动检测并下载缺失资源。

### 2. 一键安装依赖

```bash
npm install
```

会自动完成：检测 node/npm → 下载嵌入式 Python（若缺失）→ 解压 → 引导 pip → 安装 TTS/STT 依赖（`edge-tts` / `vosk`）→ 解压 STT 中文模型。

- 依赖优先使用仓库自带的**嵌入式 Python 3.11**（`python/python.exe`，Windows 下无需另装 Python），自动规避「系统 Python 过旧」类报错。
- 仅当嵌入式运行时缺失时才回退要求系统 **Python 3.8+（勾选 Add to PATH）**。
- 均不可用时 TTS/STT 降级不可用，应用仍可运行；修复后重跑 `npm run setup` 即可。

### 3. STT 模型（若首次安装后语音识别不可用）

1. 从 <https://alphacephei.com/vosk/models> 下载 `vosk-model-small-cn-0.22.zip`；
2. 放入 `stt_service/models/`（保持文件名不变）；
3. 重跑 `npm run setup` 或 `npm install` 解压。

> 解压后目录应为 `stt_service/models/vosk-model-small-cn-0.22/`，内含 `am/`、`conf/`、`graph/` 等子目录。

### 4. 启动

```bash
npm start
```

- 启动即打开**浮窗（桌宠）**作为默认窗口。
- 由浮窗气泡（鼠标靠近桌宠浮现）可进入：💬 聊天 / ⚙ 设置 / 🏠 回家（家里窗口）/ 🌸 陪伴。
- 主要窗口：**浮窗**（桌宠游荡，默认）、**家里**（`index.html`，网格房子，由「回家」唤起）、**聊天窗口**（`float.html?mode=chat`）、**陪伴窗口**（`companion.html`，语音对话）、**饼干窗口**（投喂道具）。

## 二、打包（Windows 安装包）

```bash
npm run build     # 生成 dist/ 下的 NSIS 安装包
npm run dist      # 同 build，仅打包
npm run rebuild   # 先清空 dist 再打包
```

### 打包产物与配置（`package.json` → `build`）

| 项 | 值 |
| --- | --- |
| 应用 ID | `com.example.petapp` |
| 安装包名 | `pet-app-{version}-setup.exe` |
| 打包器 | electron-builder（NSIS） |
| 包含文件 | `main.js`、`index.html`、`float.html`、`preload.js`、`css/`、`js/`、`img/`、`package.json` 等 |
| 额外资源 | `python/`（嵌入式 Python 运行时，随包分发） |
| NSIS 选项 | 可选安装路径、桌面快捷方式、开始菜单快捷方式 |

> 打包脚本 `scripts/build.js` 会自动兜底下载并安装缺失依赖。

### 打包常见问题

| 现象 | 处理 |
| --- | --- |
| 打包时依赖下载失败 | 先保证网络可用，重跑 `npm run setup` 后再 `npm run build` |
| 体积偏大 | 属正常（内嵌 Python 运行时 + STT 模型） |
| 打包后 STT/TTS 不可用 | 确认 `python/` 与 `stt_service/models/vosk-model-small-cn-0.22/` 已包含在资源内 |

## 三、设置面板完整说明

设置面板为**独立窗口**（`float.html?mode=settings`），从浮窗气泡 ⚙ 或家里窗口右上角 ⚙ 打开。所有设置存于 `localStorage`（`petConfig`），经 IPC 同步到各窗口，**改动实时生效**。

按分组逐一说明：

### 🪟 浮窗（`data-gk="window"`）

| 设置项 | 说明 |
| --- | --- |
| **小窗口桌宠大小**（40–500，默认 80） | 浮窗桌宠贴图的尺寸；影响窗口大小、物理碰撞与气泡/面板位置（用 CSS 变量 `--float-pet-size` 驱动） |
| **贴图位置偏移**（-50–100，默认 0） | 桌宠贴图相对窗口底部的上下偏移（`--float-pet-bottom`） |
| **按钮位置偏移**（-50–100，默认 0） | 四按钮气泡相对桌宠头顶的上下偏移（`--float-bubble-offset`） |
| **窗口高度附加**（0–200，默认 0） | 在所需高度之外额外增加窗口高度（给聊天/面板留空间） |
| **小窗口移动模式** | `自由游荡`（全屏随机游走）/ `重力模式`（底部行走 + 抛掷抛物线） |
| **重力模式碰撞窗口** | 开：桌宠可碰撞应用窗口反弹 |
| **生成饼干** | 开：主进程定时在屏幕角落生成可拖拽饼干道具 |
| **饼干大小**（20–80，默认 40） | 饼干窗口尺寸 |
| **小窗口聊天时显示立绘** | 聊天窗口是否显示角色立绘栏 |
| **📊 贴图下方信息条显示项**（三项） | 桌宠窗口底部半透明信息条（显示时贴图/气泡自动上移不重叠），逐项开关：<br>· **DSH 状态**：连接状态（🟢/⚪）、缓存命中率、累计花费<br>· **硬件监控**：CPU 占用 / 内存 / CPU 温度（读不到温度则省略）<br>· **当前峰谷时段**：DeepSeek 计费高峰/空闲提示（高峰：北京周一–周五 9:00–12:00 与 14:00–18:00，空闲价格减半）<br>全部关闭时信息条自动隐藏。**聊天模式下信息条自动隐藏**。 |

### 🤖 DSH 联动（deepseek-harness）（`data-gk="dsh"`）

让桌宠感知 DSH Agent 任务状态：跑任务时在右下角显示 **DSH 任务面板**（todolist、可展开实时思维链/工具流），细分任务完成时桌宠说话并切换贴图，并可直接派发/取消任务、查看 API 花费/余额/缓存命中率。**需先在 DSH 中安装 `dsh-pet-link` 插件**（见[第四章](#四dsh-联动专题)）。

| 设置项 | 说明 |
| --- | --- |
| **启用 DSH 联动** | 总开关 |
| **插件端口**（默认 43999） | `dsh-pet-link` 插件 HTTP 监听端口（桌宠状态服务固定 34165） |
| **任务运行中时覆盖（暂停）桌宠状态机** | 开：任务进行期间暂停随机状态机、由 DSH 环节决定贴图；空闲自动恢复 |
| **环节贴图状态**（六个下拉，选「不覆盖」则不切） | 💭 思考 Think / ⌨️ 命令 Pwsh / 📖 读取 Read / 🔍 搜索 Grep / ✅ 任务完成 / ❌ 任务失败，各配一个桌宠贴图状态（必须是已注册的 `浮窗_xx` 原名） |
| **派发任务给 DSH** | 输入任务 → 🚀 派发；⏹ 取消当前任务；🧪 模拟推送（让插件模拟一轮 思考→命令→读取→搜索→完成，验证链路与环节贴图） |
| **任务面板设置**（右下角蓝色面板） | <br>· **面板高度**（0=自动限高不超出窗口；100–420px）<br>· **文字大小**（10–18px）<br>· **距贴图距离**（8–90px）：面板距桌宠头顶的距离<br>· **悬停距栏**（0–60px）：鼠标靠近时面板下移到监控栏上方，这是它与监控栏的间距（自动保证不碰四按钮）<br>· **显示内容** 勾选：思维/工具、任务、Todolist、输出、统计<br>· **实时预览**：示意框实时展示面板在桌宠上方的常规位置与悬停位置、与四按钮气泡和下方监控栏的相对关系 |
| **DSH 状态监控** | 实时只读监控区：状态（连接/运行/空闲）、任务、最近工具、Todolist、最近输出、缓存命中率、累计花费、Token、余额 |

> **任务面板行为**：平时悬于桌宠头顶上方；**鼠标靠近时自动下移**（避开四按钮气泡、贴住监控栏上方），离开返回原位置——四按钮不被遮挡，面板仍可点击交互；聊天模式下信息条自动隐藏。

## 四、DSH 联动专题

### 1. 启用流程

1. 先启动桌宠应用（`npm start`），确认日志出现 `[DSH] 桌宠状态服务已启动 http://127.0.0.1:34165`。
2. 启动 DSH（Web 或桌面版），安装 `dsh-pet-link` 插件（见下），重启 DSH；日志应出现 `[pet-link] 已启动 http://127.0.0.1:43999` 与 `已从桌宠拉取状态列表: ...`。
3. 桌宠设置 →「DSH 联动」打开开关；在 DSH 里跑任务即可看到桌宠任务面板与反应，也可在设置区块直接派发任务。

### 2. 插件安装 / 重装

> 桌面版 DSH 的插件以 **generation 快照**方式管理（`.generations/live/<id>`），改动源码后必须重装并重启 DSH 才生效。

- **源码位置**：`dsh-plugin/`（`index.js` + `cordis.patch.yml` + `package.json`）。
- **重新安装（推荐）**：
  ```powershell
  node scripts/reinstall-dsh-plugin.mjs
  ```
  该脚本直接调用桌面 app 自带的 generation 安装器，重建插件快照、更新 `desired.json` 并投影 profile。完成后**重启 DSH Desktop**。
- **命令行方式（Web DSH / 其它 profile）**：
  ```bash
  # 方式 A：本地目录直接安装
  dsh plugin --profile <profile名> add /path/to/electron/dsh-plugin
  # 方式 B：发布到 npm / tarball 后安装
  dsh plugin --profile <profile名> add dsh-pet-link
  ```
- **前端脚本改动后**：`float.js` / `voice.js` 是被 base64 内联进 `float.html` 的（浮窗/聊天窗口加载的是内嵌副本），改完需重跑内联并重启桌宠：
  ```powershell
  node scripts/inline-float.mjs
  ```

### 3. 插件配置（`dsh-plugin/cordis.patch.yml`）

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `port` | `43999` | 插件 HTTP 端口，须与桌宠设置「插件端口」一致 |
| `petUrl` | `http://127.0.0.1:34165` | 桌宠本地状态服务地址 |
| `say` | 内置文案 | 任务完成时桌宠说的话，支持 `{task}` `{tool}` `{dur}` `{hit}` 占位符（任务完成 TTS 会优先播报简短的「任务完成」类短语） |
| `states` | 语义兜底 | 事件 → 桌宠贴图状态名（须是已注册的 `浮窗_xx` 原名：`工作`/`开心`/`难过`） |

### 4. 原生审批（用户确认）

`dsh-pet-link` 接管 DSH 自带的用户确认机制（`approval/request` answerer）：DSH 需要批准（bash 提权、沙箱升级、ask 策略等）时，确认推送到桌宠，桌宠弹出**中文**「🔐 允许 / 拒绝 / 取消」，选择结果回传 DSH。3 分钟未应答视为取消；确认过程记录为会话日志审计对，模型只见最终工具结果。

### 5. 数据流与端口

```
dsh-pet-link (DSH) ──POST /dsh/message──▶ 桌宠 :34165 ──IPC 广播──▶ 所有窗口
      ▲                                          │
      │ GET /status · POST /send · /cancel        │ 定时 GET /user/balance
  桌宠设置面板 ◀────IPC dsh-*──── 主进程           │
```

## 五、常见问题

| 现象 | 处理 |
| --- | --- |
| 桌宠面板显示「缓存 — / ¥0.00 / Token 0」 | DSH 桌面端还在跑旧插件代码 → **重启 DSH Desktop** 加载新 generation |
| 历史会话打不开「is corrupt」 | 旧插件注入消息时写入过非法形状，属历史损坏；新会话正常，旧会话需删除 |
| 改了 `float.js` 不生效 | float.js 被内联进 float.html → 跑 `node scripts/inline-float.mjs` 后重启桌宠 |
| 改了 `dsh-plugin/` 不生效 | 跑 `node scripts/reinstall-dsh-plugin.mjs` 后重启 DSH Desktop |
| TTS/STT 不可用 | 确认嵌入式 Python 与 STT 模型已解压，重跑 `npm run setup` |
